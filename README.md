# UNESP-Portas-Abertas

O LBMM começou em 2026 a participar do UNESP Portas Abertas, um evento promovido na UNESP para receber estudantes do ensino médio, professores e a comunidade local.

## Pasta com posteres do eventos

 * Participação em 2026: `2026/`

# Recursos computacionais

 * Computadores adquiridos com recurso FAPESP - Auxílio à Pesquisa Nova Geração (2024/19418-0)
 * Esta pesquisa tornou-se possível graças aos recursos computacionais disponibilizados pelo Núcleo de Computação Científica (NCC/GridUNESP) da Universidade Estadual Paulista (UNESP).
